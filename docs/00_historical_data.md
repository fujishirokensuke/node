## 重要な解釈

1. **リセット能力は本物** — 2021/2024/2025、いずれも夏に70kg台前半まで落とせている。「落とす技術」は身体が持っている。
2. **70kg台前半が身体の自然な底** — 10年で68kgを切ったことが一度もない。70±1kgの目標は妥当。
3. **セットポイントが10年で上昇** — 2015-2018平均 71.5kg帯 → 2019-2024平均 74-76kg帯。+4kgのシフト。これがプロジェクトの真の対象。
4. **「夏に落として秋以降に戻す」のパターン反復** — ほぼ毎年。つまりPhase 3(維持)が真の勝負どころ。
5. **2019年の転換点 = 心理的撤退** — 「見られる体である必要性」が消えた瞬間にセットポイントが上昇。カロリー収支ではなく役割と意味の問題。
6. **2022年の低体重は成功モデルではない** — 過去10年で、健康な状態で持続的に70kg台に着地した経験は実はない。

## このプロジェクトの新規性

「過去の成功を再現する」では不十分。今回が **「健康な38歳が、家族と家とパートナーシップを抱えながら持続的に70kg台を運用する」初めての挑戦**。これは負担ではなく価値。
